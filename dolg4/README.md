# Практическая работа 4. API страховой фирмы

Консольное приложение на Python выполняет учебный сценарий ОСАГО через Partner AgentApp API. Программа получает токен и использует его в HTTP-запросах. Для запуска нужны данные учебного аккаунта из задания.

## Запуск

Откройте PowerShell в папке `dolg4` и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.main
```

Подойдёт Python 3.10 или новее. Введите логин и пароль учебного аккаунта. Пароль при вводе скрыт, токен действует в пределах сеанса программы.

## Как пройти сценарий

1. Создайте водителя, собственника, страхователя и автомобиль. Для автомобиля понадобятся ID модели из справочника, VIN, госномер и данные СТС. Для физлиц понадобятся данные паспорта и коды КЛАДР из задания. При заполнении используйте учебные данные.
2. В пункте «Объект страхования» свяжите записи. Нажмите Enter, чтобы принять предложенные UUID из предыдущих шагов. Для собственника и страхователя программа подставляет идентификаторы физлиц из поля `person`. Для просмотра и изменения записей используются их верхнеуровневые `id`.
3. Выберите «Рассчитать договор». Укажите даты, код периода, параметры автомобиля и адрес регистрации собственника. Для годового периода `8` или `11` программа отправит пустой список периодов. Для `3`, `6` или `9` она попросит даты периода использования.
4. Откройте список договоров через пункт 7. Чтобы изменить договор, выберите пункт 8 и введите объект JSON с нужными полями. Для привязки другого объекта используйте `{"insured_object":"UUID объекта"}`, подставив фактический UUID.

Созданные UUID предлагаются до закрытия приложения. Для уже существующей записи можно ввести UUID вручную. При редактировании собственника, страхователя и автомобиля JSON содержит только изменяемые поля.

## Файлы

- `app/main.py` — меню и последовательность действий.
- `app/controllers/` — клиент `requests.Session`, маршруты и авторизация.
- `app/models/` — ввод данных и формирование JSON.
- `config.py` — адрес API и таймаут.
