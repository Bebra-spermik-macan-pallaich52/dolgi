# Запросы ОСАГО

Создание, просмотр и редактирование данных через готовый API AgentApp.

```bash
python -m pip install -r requirements.txt
python main.py
```

Введите тестовые логин и пароль из документации. Данные запросов — в `data.json`, ответы — в `results.json`.
Каждый запуск создаёт новые записи. Скрипт выполняет расчёт, без оплаты и выпуска полиса.
