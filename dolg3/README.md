# Регистрация на мероприятия

Консольное приложение показывает справочник мероприятий и регистрации выбранного сотрудника. Через меню можно зарегистрироваться, посмотреть детали, изменить статус или удалить свою регистрацию.

## Запуск

1. Распакуйте выданный архив `net7.0` и запустите `net7.0\WebAPI.exe`. Если Windows попросит установить среду выполнения, установите ASP.NET Core Runtime 7.0.
2. Откройте [Swagger](http://localhost:5000/swagger/index.html) и убедитесь, что API запущен.
3. В папке `dolg3` установите зависимости и запустите клиент. Требуется Python 3.10 или новее.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py
   ```

4. Введите ID сотрудника, например `1`. При создании регистрации выберите ID мероприятия из справочника. Чтобы пропустить комментарий, нажмите Enter.

На Linux с установленной средой выполнения ASP.NET Core 7.0 сервер можно запустить командой `dotnet WebAPI.dll` из папки `net7.0`.

## Структура

- `main.py` — меню и действия пользователя.
- `api/client.py` — HTTP-запросы к выданному API.
- `core/config.py` — адрес сервера и таймаут запроса.

## Запросы

| Действие | Запрос |
| --- | --- |
| Загрузить сотрудника | `GET /Employees/{id}` |
| Загрузить справочник | `GET /Events` |
| Показать мои регистрации | `GET /Registrations/employee/{employeeId}` |
| Создать регистрацию | `POST /Registrations` |
| Открыть регистрацию | `GET /Registrations/{id}` |
| Изменить статус | `PUT /Registrations/{id}` |
| Удалить регистрацию | `DELETE /Registrations/{id}` |

Список обновляется после каждого успешного изменения. Приложение сверяет владельца при просмотре, изменении и удалении. В выданном API нет авторизации пользователя по этому ID, поэтому проверка принадлежности выполняется на стороне клиента.

API принимает числовые статусы `0` (зарегистрирован), `1` (отменён) и `2` (посетил). При изменении статуса приложение также передаёт прежние ID и комментарий. Пустой комментарий отправляется как пустая строка.
