# Результат проверки задания

Выполнен учебный проект «Подключение базы данных»: Python-приложение
подключается к PostgreSQL через пул и работает с таблицей `clients`.
Реализованы просмотр всех клиентов, добавление и удаление по ID.
SQL-схема из задания сохранена без изменения.

Проверено 16 ноября 2026 года на Python 3.12.14 и PostgreSQL 16.

## Автоматические тесты

10 интеграционных тестов выполнены успешно:

1. Добавление и фиксация записи, видимой из отдельного соединения.
2. Передача апострофов и текста SQL как обычных данных.
3. Удаление существующего и отсутствующего клиента.
4. Запрет повторяющегося имени и восстановление после ошибки.
5. Запрет повторяющегося email и восстановление после ошибки.
6. Полный откат транзакции при исключении.
7. Хеш пароля и индивидуальная случайная соль.
8. Запрет удаления клиента с заказом.
9. Пагинация и порядок записей.
10. Повторные инициализация и закрытие пула.

## Дополнительные проверки запуска

- Исходный SQL импортируется в новую базу без ошибок.
- Меню добавляет, показывает и удаляет клиента; обрабатывает неверный ввод.
- Дубликаты имени/email дают понятное сообщение; меню продолжает работу.
- Вывод списка включает все 103 тестовые записи, включая записи после первых 100.
- Пароль PostgreSQL с пробелами и специальными символами корректно передаётся драйверу.
- `.env` читается из корня проекта при запуске из другого рабочего каталога.
- Импорт `app.main` не запускает меню и не открывает соединение.
- При недоступном сервере программа завершается с сообщением и кодом 1 без traceback.

Для запуска на своём компьютере выполните шаги из `README.md`:
создайте базу, импортируйте SQL, скопируйте `.env.example` в `.env`,
укажите свои параметры подключения и запустите `python -m app.main`.
